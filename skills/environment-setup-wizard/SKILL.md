# Environment Setup Wizard

Automatically configure development environments based on project detection.

## Features

- **Project Detection** - Automatically identify project type and dependencies
- **SessionStart Hooks** - Generate proper initialization scripts
- **Dependency Installation** - Install dependencies for detected languages
- **Environment Variables** - Create and manage .env files
- **Dev Server Setup** - Configure and run development servers
- **Cache Management** - Leverage container caching for faster setups

## Supported Project Types

- Node.js (npm, yarn, pnpm)
- Python (pip, Poetry, pipenv)
- Go (go mod)
- Rust (cargo)
- Ruby (bundler)
- Java (Maven, Gradle)
- PHP (Composer)
- .NET (dotnet)

## Features

- Zero-config detection
- Multi-language support
- IDE integration hints
- Async mode optimization
- Test runner configuration
- Linter setup
