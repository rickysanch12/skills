# API Client Generator

Generate fully-typed API clients from OpenAPI/Swagger specifications.

## Features

- **OpenAPI 3.0+ Support** - Parse and understand API specs
- **Multiple Languages** - Generate clients for JavaScript/TypeScript, Python, Go, Rust
- **Type Safety** - Full type definitions and autocomplete
- **Request Builder** - Interactive REST request builder
- **Mock Server** - Generate mock API servers for testing
- **Documentation** - Auto-generate API documentation

## Usage

Point it at an OpenAPI spec and get a ready-to-use API client.

## Supported Output Formats

- TypeScript/JavaScript (fetch, axios, custom)
- Python (requests, httpx)
- Go
- Rust
