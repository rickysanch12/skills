# Database Migration Builder

Intelligently generate and manage database migrations.

## Features

- **Migration Generation** - Auto-generate migration files from schema changes
- **Schema Versioning** - Track and manage schema versions
- **SQL Optimization** - Optimize queries and indexes
- **Rollback Support** - Generate safe rollback migrations
- **Data Migrations** - Handle data transformations during schema changes
- **Multi-Database** - Support multiple database engines

## Supported Databases

- PostgreSQL
- MySQL/MariaDB
- SQLite
- MongoDB
- DynamoDB
- Snowflake

## Features

- Flyway/Liquibase compatible migrations
- Zero-downtime migrations
- Index recommendations
- Query performance analysis
- Data type suggestions
