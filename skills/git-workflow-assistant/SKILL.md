# Git Workflow Assistant

Streamline git operations with intelligent automation.

## Features

- **Smart Commit Messages** - Generate conventional commits from staged changes
- **Branch Management** - Create, switch, and manage branches intelligently
- **Merge Conflict Resolution** - AI-powered conflict detection and resolution suggestions
- **Rebase Helpers** - Interactive rebase assistance and cleanup
- **Commit History Analysis** - Analyze and refactor commit history

## Usage

Use this skill to automate repetitive git tasks and follow best practices automatically.
