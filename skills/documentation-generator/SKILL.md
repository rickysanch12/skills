# Documentation Generator

Automatically generate comprehensive documentation from your codebase.

## Features

- **API Documentation** - Generate API docs from code comments and types
- **README Generator** - Create comprehensive README files
- **Architecture Diagrams** - Visualize system architecture
- **Code Comments** - Generate high-quality code comments
- **Changelog Generation** - Auto-generate changelogs from commits
- **Type Documentation** - Document interfaces, types, and schemas

## Output Formats

- Markdown (GitHub, GitLab, Notion)
- HTML
- PDF
- Mermaid diagrams
- OpenAPI specs

## Supported Languages

- JavaScript/TypeScript
- Python
- Go
- Rust
- Java
- C#
