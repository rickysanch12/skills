# Code Formatter & Linter

Automatically format and lint code across multiple languages with sensible defaults.

## Supported Languages

- JavaScript/TypeScript
- Python
- Go
- Rust
- Ruby
- Java
- C/C++
- YAML/JSON

## Features

- **Auto-Format** - Format code to consistent style
- **Lint Detection** - Find and fix common issues
- **Zero Config** - Works with sensible defaults
- **Multi-Language** - Single command for all languages
- **CI/CD Integration** - Perfect for pre-commit hooks

## Usage

Format and lint code in your project with a single command.
